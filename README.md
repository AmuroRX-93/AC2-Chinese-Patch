# 装甲核心2 中文版 0.2.5 · 零件说明校译 / True Analogs

适用于 **PS2 日版 SLPS-25007**。这是 **日文原版 → 中文 0.2.5** 的累计差分，继承已核对的 **0.2.0 True Analogs 双摇杆版**。不包含完整游戏、BIOS或个人存档。

[前往最新版下载](https://github.com/AmuroRX-93/AC2-Chinese-Patch/releases/latest) · [0.2.5 发布页](https://github.com/AmuroRX-93/AC2-Chinese-Patch/releases/tag/v0.2.5)

## 下载与安装

下载附件 **`AC2_JP_to_CHS_0.2.5_Delta.zip`**（92,670,676 字节，约 93 MB），完整解压后：

- **Windows x64**：双击 `Windows_Install.cmd`。
- **macOS Apple Silicon / Intel**：双击 `macOS_安装.command`，自动选对应架构。
- 按提示选择匹配的日文原版 ISO。**已内置 Python，无需额外安装 Python 或 pip**；程序不联网。
- 生成 `AC2_CHS_0.2.5_TrueAnalogs.iso` 后，完整校验通过再将新 ISO 加入模拟器列表。脚本不会自动启动游戏、替换游戏列表或改动记忆卡。

**不要下载 GitHub 自动生成的 Source code 压缩包来安装游戏**；仓库只放说明和安装器源文件，完整运行环境与差分数据在上述 Release 附件中。

## 已经有旧汉化版怎么更新

**本包不能直接应用到 0.1.x 或 0.2.0 的汉化 ISO。** 请用保留的、校验匹配的日文原版重新合成 0.2.5，再切换到新 ISO。

原版、旧汉化 ISO 和记忆卡不会被安装器覆盖。保留现有记忆卡，从新版正常开机读取游戏内存档；不要用旧版本即时存档/暂停状态直接恢复。确认新版本正常后再自行决定是否保留旧镜像。

## 支持的输入与输出

| 项目 | 内容 |
|---|---|
| 输入 | 日版 Armored Core 2 (Japan)，SLPS-25007，完整 ISO |
| 输入/输出大小 | 各 4,380,393,472 字节 |
| 输入 SHA256 | `fa1460abc92aa89db1806235620251f9b4cdb00a825cc0fadb36342601d088bc` |
| 输出 SHA256 | `0aac1e30565e52e2d53e6f00fbbd94dc7693aa0e60641fd869fbe67a7db76666` |

其他地区、修改版、旧汉化或 CHD 不能直接输入。程序拒绝错误版本，不要跳过校验。输出超过 FAT32 的 4 GiB 单文件上限；桌面安装建议至少 6 GB 额外空间，并选择支持大文件的磁盘。

## Android 与 PS2 实机

- **Android**：可以将电脑合成并校验的 ISO 传入手机；包内另提供标准 `.xdelta`，可尝试支持 XDelta 的第三方工具进行手机端合成。**本次没有验证 Android 上的 4.38 GB 文件合成，第三方工具可能有大文件限制。** 不附旧自制 Android 更新器。
- **PS2 实机**：先合成 ISO，再按照现有 OPL 等加载环境导入。FAT32 不能直接放此完整 ISO，需要对应的 UL 安装等流程；exFAT、SMB、HDD 各有版本与介质要求。**本次未作 PS2 实机运行验证。**
- 完整步骤和命令已放在包内《三平台安装方法.txt》《Python使用说明.txt》，不是只有一段发布文案。
