最快开始

命令与排错
所有例子都在完整解压后的 AC2_JP_to_CHS_0.3.2 文件夹执行。
路径要保留引号；尖括号示例路径请换成你的真实路径，不要原样输入。

.\runtime\windows-x64\python.exe -B -X utf8 .\tools\identify_iso.py "D:\Games\Armored Core 2 (Japan).iso"

macOS / Linux（run.sh会识别本机系统及架构）
sh run.sh "/path/to/Armored Core 2 (Japan).iso" --output "/path/to/AC2_CHS_0.3.2_TrueAnalogs.iso"
sh run.sh "/path/to/Armored Core 2 (Japan).iso" --check-only
sh run.sh --verify-result "/path/to/AC2_CHS_0.3.2_TrueAnalogs.iso"

Mac若双击入口提示权限，可在终端运行：sh macOS_安装.command
不要关闭系统安全功能。若下载文件需正常打开授权，使用系统提供的打开入口。

运行环境
推荐64位Windows 10/11、现代macOS及glibc Linux。Linux包不是Alpine/musl或Android解释器。
包内Python只使用标准库，不需要pip。每种架构的版本与来源见 Python来源.json；所列未实跑平台需要自行确认操作系统兼容性。

空间
先将ZIP完整解压。输出磁盘另留至少6GB；原版和生成镜像各约4.38GB。
不能直接在FAT32生成完整ISO。不要因为手机7z能解压，就认为输出大文件一定能保存。

常见问题
“Bundled Python is missing”：没有完整解压，或者只拿了某个脚本。入口与runtime目录应在同一根文件夹。
“Press any key”：只是窗口末尾，请看上面的首个错误。Python异常详细记录在logs目录。
“SHA256不匹配”：原版不一致或压缩包未解压；不能强行跳过检查。菜单4可帮助识别旧汉化。
“输出已存在”：换输出路径，或者先由你自己确认旧文件是否需要保留；工具不会覆盖。
“Permission denied”：确认目录有写权限；macOS/Linux可以用sh运行入口，但Python仍需执行权限，入口会尝试只给该解释器加执行位。
Linux提示缺少动态库/无法执行：核对架构与glibc发行版；未实跑的环境不要认为已通过。
中文异常或乱码：先保留首个错误和日志。不要盲改所有文件编码，也不要在压缩软件内部直接运行。
合成中断：临时输出会尽量清理，完整原版不改；异常崩溃留下.partial或.install.lock时，先确认没有安装进程，之后再手动处理这些临时文件。
运行前关掉旧游戏实例再选择新ISO，用游戏内存档恢复。旧即时状态会携带旧代码和字库。

PC 手机 实机

PC、Android 和 PS2 实机使用说明
本游戏是PS2日版SLPS-25007。先得到通过校验的0.3.2 ISO，运行内容相同，各平台入口不同。

PC
完整解压本包，用对应系统入口生成ISO，再在你已配置好的PS2模拟器中添加ISO所在目录并重新扫描。
选择新版ISO冷启动，记忆卡继续沿用；本包不包含模拟器/BIOS，不替换手柄或私人配置。

Android 有电脑
在电脑完成修补和SHA256校验；把完整ISO传到手机可访问的游戏目录；让你现有PS2模拟器通过系统文件选择器添加该目录，再扫描启动。
按键和性能按你原来已能运行日文版的配置使用。桌面runtime不能放到安卓当解释器运行。

Android 只有手机
本包 standard-xdelta/AC2_JP_to_CHS_0.3.2.xdelta 是标准VCDIFF补丁，仅用于匹配日文原版ISO。
可用明确支持XDelta的现成修补器选择三个位置：原版ISO、上述.xdelta、新输出ISO。UniPatcher官方项目说明支持XDelta：https://github.com/btimofeev/UniPatcher 。这仅说明格式能力，没有本项目对4.38GB ISO的手机安装测试；工具的版本、文件选择权限、空间和大文件限制仍需确认。
完成后核对输出SHA256：3ba0d0b7df775738df95fdb641ebf4ec74aae5e8031384da07890bc519787f12 。不能因显示“完成”便省去校验。
无法处理大文件时，使用电脑合成再传入，或使用已验证的完整汉化镜像。不要用ZIP、update.bin或manifest.json直接当游戏导入。
本包没有要求使用旧的自制Android更新APK。

PS2 实机
先合成并校验ISO，保留原版/旧版及记忆卡或VMC。再按已配置好的OPL和介质方式安装。
USB/MX4SIO：用明确支持exFAT的OPL版本时，可把ISO放入其DVD目录；具体命名按你的OPL设置。例如 SLPS_250.07.AC2_CHS_0.3.2.iso。
FAT32：本ISO超过4GiB，不能直接复制。需用你已验证的USBExtreme工具转换（如OPLUtil/USBUtil），普通文件切片或7z分卷不等同USBExtreme格式。
SMB：按已有共享目录的DVD结构部署完整ISO；修改版本只替换对应游戏，不删除VMC、CFG或其他游戏。
内置HDD：按已有APA/HDLoader安装流程和工具导入；不能把ZIP当作HDD游戏包。
OPL官方说明支持介质和大文件方式：https://github.com/ps2homebrew/Open-PS2-Loader 。其README在2026-10-10核查说明USB/MX4SIO/iLink的exFAT从v1.2.0 beta rev1880支持，FAT32超过4GB用USBExtreme。须核对自己实际版本，不为汉化盲目格式化现有盘。
本版尚未进行PS2硬件或Android游戏内验证。也不把PS2 ISO当作PS3/PSP原生游戏。
